# SQL Server lesson factual audit - 2026-10-02

All 24 canonical lessons were read, including sections, examples, exercise prompts, solutions, checks and quiz answers. Setup and advanced import fixture/solution files were inspected. Microsoft primary documentation was consulted for the specific claims cited below. This is a complete reading record with bounded verification, not certification of all engine versions or production deployments.

Fresh execution used Windows authentication and sqlcmd against local SQL Server 2025 Express 17.0.1000.7. Runnable example/solution blocks from 23 lessons ran in separate connections, with session-local synthetic tables in tempdb. Setup database-creation/context guards were omitted from the harness; the fixture definitions and lesson SQL were retained. Prose/pseudocode was not passed to the engine. SQL source version claims were checked against current documentation; only the installed 2025 engine was run.

The historical engine-verification.md was left unchanged and is not presented as fresh evidence. Live two-session races, Query Store capture/forced-plan behavior, real role permissions, backup/restore, production migrations and optional extensions were not rerun. A query returning no Query Store rows in tempdb does not verify capture behavior. Browser/SSMS interactions were not tested. Every quiz was reviewed against its stated model; business-policy exercises remain scenario-specific.
