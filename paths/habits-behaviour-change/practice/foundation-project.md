# A factual baseline and a feasible target

## Brief

Complete the following requirements using the related numbered worksheets. Use a fictional case or a low-stakes voluntary practice; no personal disclosure is required.

1. State a useful outcome and a controllable action.
2. Record three opportunities with context, completion and constraints.
3. Choose a recognised cue and a useful minimum.

## Worked fictional project

Mira uses a keys-in-bowl target. She records available arrival opportunities, tries moving the bowl nearer the door, and keeps it if retrieval is easier. A missed arrival cue prompts a next-opportunity plan; a short log cannot prove automaticity or universal causation.

## Exit criteria

- State a useful outcome and a controllable action.
- Record three opportunities with context, completion and constraints.
- Choose a recognised cue and a useful minimum.
- Record known facts and uncertainty separately, using the relevant stage measures.
