# 6. Pause long enough to choose the purpose

## Aim

A brief pause can help you decide what a conversation needs to accomplish.

Before replying, identify the practical issue, what information is missing and the smallest useful request. A pause can be as simple as drafting without sending. It is a choice about timing, not a claim that all emotion must disappear before speaking.

## Mechanism and practical trade-off

Urgent information and a broader concern may require separate timing. First clarify the location needed for today; later discuss how changes should be announced. Separating purposes is useful only if the broader issue receives a real follow-up. Otherwise postponement can become avoidance, so specify when and how the second discussion will happen.

## Fictional case

Kiran drafts an angry response to a last-minute room change but mainly needs to know where to meet.

## Your practice

Rewrite the reply around its immediate purpose.

Observation / known facts: ________________________________________

Interpretation / uncertainty: _____________________________________

Proposed next action and timing: __________________________________

Constraint or exception: __________________________________________

Evidence to review afterwards: ____________________________________

## Worked fictional response

I saw the room changed. Please confirm the new location and whether the start time is the same. We can discuss notice for future changes afterwards. The first message solves the urgent information gap while preserving a later concern.

## Self-check

- Urgent purpose and later concern are distinguished.
- The reply requests the needed information.
- Compare your answer with the example. Explain any different choice.
