# Five companion paths in one week

Each companion is optional: the journey includes the concepts needed to complete its fictional scenario.

| Companion | Concrete contribution | Lesson connection |
| --- | --- | --- |
| [Time, Attention and Energy](https://abdul-shaikh-dev.github.io/learning-notebook/index.html#path/time-attention-energy) | Count working hours after breaks; check quiet windows and low-energy conditions | calendar-energy |
| [Task and Project Management](https://abdul-shaikh-dev.github.io/learning-notebook/index.html#path/task-project-management) | Clarify event outcome, next actions, Lee dependency and follow-up | outcomes-next-actions |
| [Habits and Behaviour Change](https://abdul-shaikh-dev.github.io/learning-notebook/index.html#path/habits-behaviour-change) | Three-minute close-of-day waiting note plus one-minute fallback | supporting-habit |
| [Self-awareness and Communication](https://abdul-shaikh-dev.github.io/learning-notebook/index.html#path/self-awareness-communication) | Name worry separately from capacity; request an owner trade-off | communicate-tradeoffs |
| [Learning How to Learn](https://abdul-shaikh-dev.github.io/learning-notebook/index.html#path/learning-how-to-learn) | Observable target, retrieval, correction and delayed new-case check | learning-in-week |

These hosted links work from the downloaded worksheet when an internet connection is available. The printed path names and exact IDs remain usable offline. Do not require a learner to finish all five before planning a week.
