# Plan and Review Your Week: printable journey

No technical knowledge, account or installed app is required. Use paper or any text viewer. Extract the bundle and keep its files together. Sam's week and every filled record are synthetic examples; they are not your personal evidence.

Suggested task order:

1. Read lessons 1–6. Complete the five numbered tasks in foundation-kit.md using the blank week-planner.md before viewing the filled plan.
2. Read lessons 7–11. Complete the five tasks in intermediate-kit.md. Keep both original and revised plans.
3. Read lessons 12–15. Use the short task in advanced-kit.md: one next-week plan and one reason for a change. The longer worksheet and portfolio are optional.
4. Use the project criteria as optional prompts to check your reasoning. No score or completed paperwork is required to continue reading.

Files: foundation-kit.md supplies the full scenario and constraints; intermediate-kit.md supplies disruptions and decision-owner agreement; advanced-kit.md supplies actual synthetic outcomes and a worked review; week-planner.md and review-and-next-week.md include blank sheets plus filled examples; companion-map.md links five optional companion paths and explains their concrete contributions; research-and-limits.md gives source boundaries.

The journey can be completed entirely with the fictional week. If adapting it to your life, check real commitments, keep private details private, and use actual evidence. A future experiment is a proposal until you perform it. No automated score can establish personal improvement from these worksheets alone.

## Interactive practice studio

Open `lab.html` in a browser with `lab.js`, `lab-model.js` and `lab.css` beside it. No installation, account or external service is required. Use the five activity buttons for capacity planning, a keyboard-accessible task board, a habit experiment, a recall card and a conversation scenario.

These are educational models: the capacity sketch does not schedule overlapping appointments; a chosen review date does not create a reminder; a conversation opening cannot guarantee agreement. All entries stay in page memory and reload clears them. Use **Export my practice** to keep a private JSON copy. **Restore an exported practice file** validates and previews it before you choose **Replace page entries**. This restores all five activities without a server or automatic sync. Older exports restore an equivalent capacity result, but you should review the reconstructed buffer percentage and disruption input. The notebook backlink works in the hosted site; from an extracted kit it may not resolve, and you can return to the notebook using your own bookmark.

These lessons follow one evolving situation. Read the worked case first; try a changed case aloud or in your own tools when useful. No extra worksheet or written submission is required. These fictional cases provide reasoning practice, not a validated assessment.
