# Pull work when capacity exists: printable worksheet

Use this fictional case. You can answer aloud or make a short note; the space below is optional.

## Read

Pull means selecting ready work when the workflow has capacity. It differs from assigning an unlimited queue of simultaneous promises. Selection still considers value, risk and deadlines; a vacant slot does not require starting a low-value item.

## Try before reading the answer

One item finishes under a WIP limit of two; choose between a ready dependency and a vague optional redesign.

## Worked example

Pull the ready dependency if it supports the workshop outcome. Clarify or leave the optional redesign in the backlog. Capacity is a permission signal, not an obligation to start arbitrary work.

## Check your answer

- Check capacity after the completed item exits.
- Compare readiness and value of the two options.
- Leave the vague item unstarted until clarified.
