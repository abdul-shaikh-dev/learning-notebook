# Manual audit evidence

Record date, browser/version, operating system, assistive technology/version (if used), viewport and input method. Mark each item Pass, Fail or Not executed; include exact reproduction and user impact.

1. Tab to Skip to main content, activate it, and confirm focus/location reaches main.
2. Reach title and Add lesson in meaningful order with visible unobscured focus.
3. Submit spaces: observe visible required error, invalid state and focus on title.
4. Enter a real title: error clears, list changes and the status communicates the change.
5. Open Preview: its title is named, focus enters, Tab/Shift+Tab stay inside; Escape and Close dismiss it and return focus to Preview.
6. Try 320 CSS pixels, 200% and 400% zoom. No whole-page horizontal scroll or missing controls. Record exceptions.
7. Increase text spacing and try a long lesson title. Content wraps and remains visible.
8. Enable reduced motion. Adding a row preserves the information without animation.
9. Check forced colours/high contrast and actual colour contrast in each state.
10. With a screen reader, navigate landmarks/headings/form names and inspect error, status and dialog announcements. Record actual tool/version, or Not executed.
11. Have another person find the checklist and add a lesson without hints. Record obstacles and assistance.

The semantic test is not a WCAG conformance audit. No physical device or screen-reader execution is implied by this checklist.
