# Foundation kit: a first checked learning loop

## Supplied fictional policy

This is the entire policy for practice. Planned requests of two or more days need a manager. Planned one-day requests need a coordinator. Urgent same-day requests need a manager regardless of duration. These rules are invented, not advice about your employer.

## Exact tasks

1. Write a target: explain and correctly route requests under all three rules. Record today's date and support used.
2. Read the policy once. Close it. Answer baseline A: planned three days; B: urgent today for one day; C: planned one day. Give both route and reason. Do not alter original responses after checking.
3. Open the key below. Count a case correct only when both route and reason match. Record the count out of three. Identify a missed decision.
4. Create two prompts without the answer visible. Attempt them with the source closed, check and write a corrected explanation. Record a later date that is actually available.
5. On that later date, answer D: planned two days; E: urgent today for half a day; F: planned one day next month. Check and record count, gap and support. If the date has not occurred, write pending.

## Answer key — read after your attempt

A manager because planned duration is at least two days. B manager because the urgent same-day override applies. C coordinator because it is planned and one day. D manager because planned duration is two days. E manager because urgency overrides the ordinary short-duration route. F coordinator because it is planned one day. Next month does not make it urgent today.

## Fully filled synthetic example

Target: by Friday explain the three rules and route new cases. Tuesday baseline: A coordinator because all planned requests use coordinator; B coordinator because one day; C coordinator because planned one day. Score 1/3. These original wrong answers remain in the log.

Correction: planned duration of two or more days goes to a manager; urgent same-day requests also go to a manager, including one day. Two prompts: who handles a planned four-day request and why? Who handles an urgent same-day one-day request and why? Tuesday attempt answers manager for both, with correct reasons; source checked afterward.

Friday, three-day gap, no source during answering: D manager because two days; E manager because urgent today; F coordinator because planned one day. Score 3/3. Conclusion: improvement on these small comparable sets; not proof of permanent retention or every workplace policy.

## Check your attempt

Use these questions to check your attempt: Is the target clear? Did you check both the approval route and the reason? Can you see what you corrected? Did you try a new case after a gap and note any help you used? Scoring is optional. If the later check has not happened, mark it pending and return when you can.
