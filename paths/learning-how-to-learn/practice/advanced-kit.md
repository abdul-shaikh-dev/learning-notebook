# Advanced kit: delayed application and transfer

## New supplied fictional booking rule

Planned room bookings under two hours go to reception. Planned bookings of two hours or more go to facilities. Urgent same-day bookings go to facilities regardless of duration. The new threshold is hours, not leave days; approver names have changed.

3. Read the new booking rule, then close it and route these cases with reasons: planned one-hour room; urgent half-hour room today; planned two-hour room. Explain the shared principle and the changed details.
4. Evaluate this claim: memorising leave cards guarantees safe machine operation. State the measured outcome, missing evidence and one source you would consult.
5. Decide which prompts to maintain, revise or retire. Explain what happens if the policy changes.
6. Write a portfolio conclusion with demonstrated result, unresolved result, limitation and next step. Score the rubric and repair the missing criterion.

Boundary: real policies must be checked; these invented rules grant no actual authority.

Claim evaluation: the original card work tests recall and case decisions, not operation of equipment. Evidence about delayed memory does not establish safe procedural performance. ## Failed-transfer alternative

If you answer coordinator for the half-hour booking, record that actual error. You carried the old approver into the new context. Repair by rereading the new policy and explaining the changed details, then attempt a fresh booking case later. Improved leave recall can coexist with unestablished transfer.

## Rubric

0 missing / 1 partial / 2 complete: retained comparable delayed evidence; changed-case explanation with verified new rules; careful evaluation of research claims; bounded conclusion and next action. All four need 2. An incorrect case is not concealed: correct and retry it, retaining the original evidence. The portfolio demonstrates this small target, not universal expertise.
